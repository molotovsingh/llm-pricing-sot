individually-green commits.** The per-token catalog — verified exact for proprietary
and hosted open-weight models, structurally blind to specialist and self-hosted ones —
is now a *verifier*. The truth for cost is what the user actually runs, priced in its
native unit and attested. Every acceptance criterion in the spec was checked by
experiment against the real cache, not by reading the diff. **No open P1.** The
residue is data the user must own (which hosts, which GPU, a bench measurement) and one
carried-forward human decision.

## Defects found *during* the refit, and what they say

Four things went wrong while building this, each caught by a check rather than by luck:

1. **`stream=sys.stderr` as a default parameter** bound the stream that existed at import,
   so `redirect_stderr` never saw the table — surfaced as an `IndexError` in a new test.
   Fixed in both table printers; the review-table one had been latent since `374f234`.
2. **Truth-file paths as default parameters** made hermetic tests read the shipped
   `deployments.json` — and they *passed*, because today's seeds looked valid on the
   wall clock; only a pinned-past-clock test class went red. Fixed by resolving paths at
   call time and patching once in `setUpModule`.
3. **A second `setUpModule`** silently shadowed the first (the network guard). Found by
   instrumenting the patch and seeing the constant unchanged. Merged into the existing hook.
4. **A missing host alias** (`featherless-ai`) — the declared-not-inferred design doing
   its job: it failed loudly instead of merging fuzzily.

**T3 — defaults bound at import.** Items 1 and 2 are the same shape: a default parameter
captures a value at definition time, so anything that later redirects or patches the
underlying name is invisible to it. Two instances in one day is a pattern. The repo now
resolves such values at call time (`stream = stream or sys.stderr`;
`deployments_path or DEPLOYMENTS_PATH`). Worth carrying as a review lens.
