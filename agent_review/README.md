# agent_review

Agent-authored review artifacts for this repo. `quality-pass/` holds recurring
engineering-quality passes — one report per commit.

- **`quality-pass/latest.md`** — the current report; start here.
- **`INDEX.md`** — chronological history mapping runs to commits.

Reports are frozen once `HEAD` advances past their commit; the value is the diff
between runs. Nothing here is generated by the build — it is written by an agent
running `/quality-pass` and committed on its own.
